# AI Session Log

Copy to `docs/99_ai-sessions/`. Replace prompts with evidence; use `n/a: reason` only when justified.

```yaml
ai_assisted: false
ai_session_id: null
human_reviewed: false
reviewer: null
reviewed_at: null
reviewed_revision: null
```

## Task and inputs

Name task, UC/ACs, model/session ID, inputs and their revisions. Exclude credentials.

## Changes and verification

Link the diff, allowed scope, verification command, result and candidate revision.

## Human review

Keep pending until a named human records acceptance/rejection on the exact revision, with date and evidence.
