# Slim brief

Replace each instruction with project-specific evidence. See the worked example.

## Problem

Name user, pain, current workaround, success measure, effort estimate and kill criteria.

## Scope and acceptance criteria

Define one slice, non-goals and UC/AC IDs with happy path, failure states and I/O.

## Architecture and infrastructure

Name module ownership, dependency direction, data model, deployment, secrets, backup and cost. Mark genuinely inapplicable items with reasons.

## GO decision

Record reviewer, date, spec revision, planning checklist results, open warnings and expiring overrides. Red blockers prevent GO.
