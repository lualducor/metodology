# Slim checks

Replace each instruction with project-specific evidence. See the worked example.

## Verification evidence

For each AC record check, result, evidence path, tested commit, spec revision and reviewer/date. Changed inputs invalidate affected approvals.

## Production readiness

Record critical error behavior, secrets check, rollback, logs, env, backup and relevant performance checks; justify n/a items.

## Release and rollback

Record release revision, delivery steps, known limitations and a rollback walkthrough result.

## Observation

Record success measurement, feedback, next action and keep/iterate/maintain/sunset decision.
