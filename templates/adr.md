# Architecture Decision Record

Copy to `docs/03_architecture/decisions/`. Replace prompts with evidence; use `n/a: reason` only when justified.

```yaml
ai_assisted: false
ai_session_id: null
human_reviewed: false
reviewer: null
reviewed_at: null
reviewed_revision: null
```

## Context

State the decision to make, constraints, evidence and alternatives.

## Decision

Record the chosen option, owner, date and revision it applies to.

## Consequences

Record benefits, costs, accepted limitations and the condition for revisiting this choice.
