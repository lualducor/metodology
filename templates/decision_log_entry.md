# Decision Log

Copy to `docs/decisions.md`. Replace prompts with evidence; use `n/a: reason` only when justified.

```yaml
ai_assisted: false
ai_session_id: null
human_reviewed: false
reviewer: null
reviewed_at: null
reviewed_revision: null
```

## Decision

Record the chosen option, owner, date and revision it applies to.

## Reason and alternatives

Explain why this choice fits the constraints and which alternatives were rejected.

## Owner and date

Record the accountable person, date and any review/expiry date.

## Linked evidence

Link relevant spec, code, tests, risks and review revisions.

For an orange override include gate ID, reason, accepting owner, expiry (default 14 days) and linked decision. Red blockers cannot be overridden.
