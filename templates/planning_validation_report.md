# Planning validation report

## Candidate and scope

Record project, tier, slice, spec/contract revisions, date and human reviewer.

## Planning checks

For each of the 12 `planning_validation_gate.checks` in the manifest, record
ID, applicable scope, pass/fail/n/a, evidence and rationale. Decision Log presence
has no entry quota. No worker usage makes the agent review roll-up n/a, with reason.

## Decision

GO only when all red checks pass, orange failures have current documented overrides,
and evidence is reviewed. Yellow advisories need no override. Record human decision
and next action; this report is completed manually, not generated by the validator.
